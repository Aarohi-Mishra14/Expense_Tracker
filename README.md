# Expense_Tracker
A simple expense tracker built with HTML, CSS and Vanilla Javascript.

🔗 Live demo: https://expense-tracker-eta-pearl.vercel.app

## Features

- Add salary and track expenses (name, amount, category, date)
- Real-time remaining balance calculation
- Delete, search, filter and sort expenses
- Data saved in local storage (persists after refresh)
- Expense breakdown chart using Chart.js
- Download expense report as PDF using jsPDF
- Low balance warning when balance drops below 10% of salary
- Currency switcher (INR/USD/EUR/GBP) using live exchange rates

## Tech Used

- HTML, CSS, JavaScript (no frameworks)
- Chart.js
- jsPDF + jsPDF-AutoTable
- Frankfurter API (currency rates)
